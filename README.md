# Madrinha Ana ao Resgate 🌡️

Jogo de navegador. Para jogar, abra `index.html` (duplo clique) no Chrome, Firefox, Edge ou Safari. Não precisa instalar nada.

- Mover: setas ou WASD (no celular, arraste o dedo na tela)
- Encoste nas pessoas com 💧 para refrescá-las
- Reabasteça nas fontes ⛲; fique na sombra 🌳 para esfriar a Ana
- Pegue 🍦 para correr mais rápido
- Fases ímpares: pátio ao ar livre; fases pares: sala de estar (mais fresca)
- Se alguém (ou a Ana) chegar a 100 de calor, o jogo acaba
